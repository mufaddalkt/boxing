# Ring Rivals — Mariyah vs Moiz 🥊

An offline, mobile-friendly HTML5 boxing game featuring **Mariyah vs Moiz**.

## Play
Open **[the game](https://boxinggamebymariyah.vercel.app)** in a phone or desktop browser, or save `index.html` and open it offline. No external images, fonts, sound files, or packages are required.

## Mobile controls
- **◀ / ▶**: Hold to move Mariyah.
- **🥊 PUNCH / 💥 HOOK / 🦵 KICK**: Tap or hold to attack.
- **JUMP / BLOCK**: Defensive buttons.
- You can move and punch at the same time using **two fingers**.
- Portrait mode has a camera that follows both fighters. Landscape mode shows the ring and controls side by side.

## Desktop controls
**Mariyah**: A/D to move, W jump, S block, F or Space jab, G hook, H kick.
**Moiz** (2-player mode): ←/→ to move, ↑ jump, ↓ block, J jab, K hook, L kick.
Press **P** to pause.

## Features
- Fair computer-opponent mode and local two-player mode.
- Boxing ring, 2,000 animated spectators, and food courts.
- Scoreboard with points, round wins, health, stamina and countdown.
- Original generated sound effects and rhythmic background soundtrack, with a mute switch.
- 3-round championship, knockouts, and a restart button.

## Hosting
This is a static site. Set the Vercel root directory to the repository root and the framework preset to **Other**; no build or install commands are needed.

**Files:** `index.html` (complete HTML, CSS and JavaScript game); `README.md` (this guide).
